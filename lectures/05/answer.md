  - `uv run python -m app.retrieval "LoRA QLoRA 違い"` でヒットしたページ：
    1. lec02-main p.52「LoRA と QLoRA：大きなモデルも GPU 1 台で調整できる」

    3. lec02-main p.60「今日の演習：QLoRA で出力形式を矯正し、効果を測る」
    4. lec02-main p.47「根拠と諸説：知識の追加は RAG が効きやすい」
    5. lec02-main p.61「演習の進め方と提出物（仮）」
  - 本文で確認できたこと：
    - LoRA は元の重み $W$ を固定し、低ランク行列 $A$・$B$（細長い2つの小さな行列の積）だけを学習する。学習対象は全体の 1% 未満にできる。
    - QLoRA は LoRA に加え、元の重みを 4bit に量子化して保持する。7B モデルなら約 4GB で、48GB GPU 1 台で 650 億パラメータの微調整が可能（QLoRA 論文）。
    - PEFT の系譜（Adapter／Prefix・Prompt Tuning／LoRA／QLoRA）の位置づけも p.51 で確認できた。

- `--trace`で見えたツール呼び出し（ツール名・引数・回数、Treeでたどった目次など）：
  - retrieval（デフォルト）：`search_materials({'query': 'LoRA 固定 学習 QLoRA 加える'})` ×1 回、モデル応答 2 回。
  - Tree：`browse_tree` を 4 回連鎖で呼び出し。
    1. `browse_tree({})` → ルート（lec01／lec02／lec03）
    2. `browse_tree({'node_id': 'lec02-main'})` → 第2回の章一覧
    3. `browse_tree({'node_id': 'lec02-main-s045'})` → 章「選んだモデルを、いつ・どう直すか」のページ一覧
    4. `browse_tree({'node_id': 'lec02-main-p052'})` → 末端ページ（本文 717 文字）取得
    - モデル応答 5 回。
  - Graph：`search_graph({'query': 'LoRA QLoRA 固定 学習 第2回'})` ×1 回、モデル応答 2 回。
  - full-context：ツール呼び出しなし（全文を一括投入）、モデル応答 1 回。

- 取得した情報が足りなかった例、取得できたのに回答へ使えなかった例：
  - 足りなかった例：全文投入では入力量が巨大なため QLoRA の核心（「4bit に圧縮」）の明示が弱まり、「どう圧縮するかは資料を確認してください」とヒント止まりになった。情報は含まれていたが要点抽出に失敗。
  - 使えなかった例：ベクトル検索は p.47（RAG と FT の比較）や p.60・61（演習進行）もヒットしたが、質問の論点（LoRA/QLoRA の仕組み）とは直接関係が薄く、回答本文には反映されなかった。

- 今回の用途に採用したい方式と、その理由・比較条件の限界：
    - 理由：最安（$0.0013）・応答回数 2 回・回答も簡潔で正確。日常的なピンポイント質問には十分。
    - 構造的に辿るため、章全体の文脈を踏まえた最も詳細な回答が得られた（ただし時間・コストは増える）。
    - 質問が1件のみで統計的な一般化はできない。
    - QLoRA/LoRA のように第2回 p.52 に明確な記述がある「特定ページで完結する」質問だったため、検索方式が有利に働いた可能性がある。横断的な知識統合が必要な質問では結果が変わり得る。
    - full-context の 503 エラー（混雑）など外部要因の影響も考慮が必要。

- 気づき・疑問：
    - full-context は速度こそ最速だが、入力トークン量が他方式の 10〜40 倍で、コストが約 27 倍に膨らむ割に回答品質は必ずしも最良ではない。
    - Tree はツール呼び出し回数が多くても、1 回あたりの入力が小さく総コストは Graph と同程度に収まる。
    - 同じ資料でも、要点抽出能力は「渡し方（スコープ設計）」に大きく依存する。
    - Graph モードが参照する「関連エッジ」は、どの指標（共起／リンク／類似度）で張られているのか。
    - 検索結果のトップ k 件数を変えた場合、ベクトル検索の回答品質はどの程度変わるか。
    - 混雑時（503）のリトライ戦略はエージェント側で自動化されているのか、ユーザー側の再実行に委ねられているのか。
